# 05: GitHub 공개 저장소와 Vercel 배포

**What to build:** 채점자가 public GitHub 저장소와 Vercel 배포 URL에 접속해 방명록의 작성, 조회, 수정, 삭제와 비밀번호 불일치 거부를 실제로 확인할 수 있게 합니다. 권태현 님의 GitHub와 Vercel 계정 로그인이 필요해서 사람이 해야 하는 티켓입니다. 에이전트는 명령과 확인 절차를 안내합니다.

**Blocked by:** 02 (Entry 작성과 목록 조회)에 막혀 있습니다. 02가 끝나면 첫 배포를 할 수 있습니다. 최종 제출 확인은 03 (Message 수정)과 04 (Entry 삭제)가 끝난 뒤에 합니다.

**Status:** ready-for-human

### 이름 규칙
- [ ] GitHub 저장소 이름이 `guestbook-202204175`이고 **public**이다
- [ ] Vercel 프로젝트 이름이 `guestbook-202204175`다
- [ ] Neon 프로젝트 이름이 `guestbook-202204175`다(변경 완료, 재확인만)

### 배포
- [ ] 로컬 저장소에 GitHub remote가 연결되어 있고 코드가 push되어 있다
- [ ] 커밋 이력 어디에도 `.env.local`이나 `DATABASE_URL` 값이 없다
- [ ] Vercel 프로젝트 환경변수에 `DATABASE_URL`이 설정되어 있다
- [ ] Vercel 빌드가 성공하고 배포 URL이 열린다. Neon 콜드 스타트 때문에 첫 확인까지 10분 정도 걸릴 수 있다

- [ ] 개발자 `권태현 (202204175)`가 보인다

- [ ] 조회: 새로고침해도 전체 목록이 최신순으로 보인다
- [ ] 수정: 올바른 비밀번호로 Message가 바뀌고 "(수정됨)"이 보인다
- [ ] 수정 거부: 틀린 비밀번호로 수정하면 거부되고 "비밀번호가 일치하지 않습니다"가 보인다
